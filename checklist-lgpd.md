# Check-list de Adequação à LGPD (Lei Geral de Proteção de Dados)

Este documento serve como um guia prático de verificação para o mapeamento e conformidade de dados pessoais em um ambiente corporativo, alinhado aos princípios da LGPD (Lei nº 13.709/2018).

## 1. Mapeamento e Inventário de Dados (Data Mapping)
- [ ] Identificados todos os dados pessoais coletados (nome, e-mail, CPF, IP, etc.).
- [ ] Identificados dados pessoais sensíveis (saúde, biometria, religião, etc.).
- [ ] Mapeado o fluxo de dados: onde os dados entram, onde são armazenados e com quem são compartilhados.
- [ ] Identificada a base legal aplicável (consentimento, legítimo interesse, obrigação legal, etc.) para cada operação de tratamento.

## 2. Direitos dos Titulares (Data Subject Rights)
- [ ] Canal ou procedimento estruturado para atendimento a solicitações dos titulares.
- [ ] Processo implementado para confirmação de existência de tratamento e acesso aos dados.
- [ ] Fluxo estabelecido para correção de dados incompletos, inexatos ou desatualizados.
- [ ] Mecanismo para exclusão ou anonimização de dados quando aplicável.

## 3. Segurança e Governança
- [ ] Implementação de controles de acesso baseados em privilégio mínimo (RBAC).
- [ ] Criptografia aplicada a dados pessoais em trânsito e em repouso.
- [ ] Plano de resposta a incidentes de segurança voltado a vazamento de dados pessoais.
- [ ] Definição formal do papel do Encarregado de Dados (DPO) e canal de contato público.
